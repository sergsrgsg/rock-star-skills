# Changelog

## 0.1.0 (2026-04-06)

### Added
- LLM Wiki skills: `llmwiki:init`, `llmwiki:ingest`, `llmwiki:search`, `llmwiki:optimize`, `llmwiki:health`
- MD5-based source change detection via `.manifest.json`
- qmd integration for hybrid BM25/vector search
- Health scoring with source drift detection
- Wiki page conventions: frontmatter, wikilinks, kebab-case filenames
